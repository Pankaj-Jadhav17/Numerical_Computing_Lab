Numerical Computing Project

Run:
python3 main.py

Install:
pip install -r requirements.txt

The program contains:
1. Forward Difference
2. Backward Difference
3. Central Difference
4. Central Second Derivative
5. Richardson Extrapolation
6. Newton Interpolation (Divided Differences)

Input files are stored in input/.
Generated results are stored in output/.

Class Hierarchy:
  InterpolationBase (ABC)
    └── DividedDifferences
          └── NewtonInterpolation
